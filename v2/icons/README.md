# 아이콘 파일 안내

이 폴더에는 크롬 확장 프로그램용 아이콘들이 필요합니다:

- icon16.png (16x16 픽셀)
- icon32.png (32x32 픽셀)  
- icon48.png (48x48 픽셀)
- icon128.png (128x128 픽셀)

아이콘 디자인 가이드:
- 🇰🇷 + 📺 조합 또는 "KO" 텍스트 사용
- 깔끔하고 인식하기 쉬운 디자인
- 배경 투명 또는 흰색
- PNG 형식

온라인 아이콘 생성 도구:
- https://favicon.io/
- https://realfavicongenerator.net/
- https://www.canva.com/

임시로 사용할 수 있는 Unicode 이모지:
🇰🇷📺
