# Privacy Policy for Udemy Korean Subtitle Generator

**Last updated: August 29, 2025**

## Information We Collect

This extension collects minimal information necessary for functionality:

### Local Storage Only
- **Google Cloud Translation API Key**: Stored locally in Chrome storage for translation services
- **Usage Statistics**: Monthly character count stored locally for quota management
- **User Preferences**: Subtitle style settings (font size, width, position) stored locally

## How We Use Information

### Translation Services
- API key is used exclusively to authenticate with Google Cloud Translation API
- Subtitle text is sent to Google Cloud for translation purposes only
- No translation content is stored by this extension

### Local Functionality
- Usage statistics help track monthly API quota limits
- User preferences improve subtitle display experience
- Subtitle position is remembered for user convenience

## Information Sharing

### Third-Party Services
- **Google Cloud Translation API**: Subtitle text is sent for translation only
- **No other third parties**: We do not share information with any other services

### Developer Access
- **No remote access**: All data remains on user's device
- **No analytics**: We do not collect usage analytics or tracking data
- **No personal data**: We do not access or store personal information

## Data Storage and Security

### Local Storage
- All data is stored locally in Chrome's secure storage system
- No data is transmitted to external servers (except Google Translation API)
- Users can clear all data by removing the extension

### Data Retention
- Data persists only while extension is installed
- Uninstalling the extension removes all stored data
- No backup or recovery systems are maintained

## User Rights

### Data Control
- Users can view stored data through Chrome's extension storage
- Users can reset settings through the extension popup
- Users can delete all data by uninstalling the extension

### API Key Management
- Users provide their own Google Cloud API keys
- Users can change or remove API keys at any time
- API keys are never transmitted to our servers
